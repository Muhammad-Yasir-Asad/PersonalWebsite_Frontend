# Personal Website — Frontend

A simple personal website built with **HTML and CSS**. This project explores page structure, typography, spacing, and the fundamentals of presenting personal or portfolio information on the web.

## ✨ Features
- HTML-based page structure
- Custom CSS styling
- A starting point for a personal portfolio
- Lightweight frontend with no build step required

## 🛠️ Tech Stack
- HTML5
- CSS3

## 🚀 Run Locally
1. Clone the repository:
   `git clone https://github.com/Muhammad-Yasir-Asad/PersonalWebsite_Frontend.git`
2. Open `index.html` in your browser.
